# Agent Guidelines

## Git workflow
- Work directly on `master` (the main branch); push every change to `master`.
- One commit per fix or feature — never bundle unrelated changes.
- Write clear commit messages describing the fix or feature.

## Documentation
- Update docs with every fix or feature: `README.md`, `CHANGELOG.md`, and `docs/` as relevant.
- Docs changes go in the same commit as the code they describe.
